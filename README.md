## 🎨 How to Customize

### 1. Change Profile Pictures:
- Simply replace `assets/images/profile.jpg` with your own photo, or update the `src` attribute in `index.html`:
  - Home image: Search for `id="heroImage"` in [index.html](file:///c:/Users/DeLL/Desktop/portfolio_bandari22/index.html)
  - About image: Search for `id="aboutImage"` in [index.html](file:///c:/Users/DeLL/Desktop/portfolio_bandari22/index.html)

### 2. Add Your CV:
- Put your PDF resume inside `assets/` and name it `cv.pdf` (or edit the `href="assets/cv.pdf"` in the hero button).

### 3. Update Projects & GitHub Links:
- Search for `.project-card` in `index.html` to update the titles, descriptions, and repo URLs.
